# 歌のMVをドズル社メンバーでなぞるショート(MVパロディ)の作り方

将棋一番！おんりー版(2026-10-20・L9AilZBan4o)で、殿の指摘を受けて一つずつ直した手順をまとめた。
最初の版(止め絵42枚・0.5秒刻み)から完成版(v8g・描いた絵245枚・本家とコマ単位で同期)まで、殿の指摘は30回以上あった。
同じ型のショートを作る時は、**この順に測ってから作る**。

- 組み立ての道具: `projects/dozle_kirinuki/scripts/mv_parody/shogi_ichiban/`(build_v7.py ほか。作業場は `work/shogi_ichiban/`)
- 教訓の memory: `feedback_mv_parody_measure_reference_first`

## 0. 曲と区間を決める

1. 殿が出した音源のページ(`youtube.com/source/<音源ID>/shorts`)から、伸びているショートを yt-dlp で落とす(480p・`--flat-playlist` で一覧を取る)。
2. 各ショートの音を本家 MV の音と相互相関させ、**曲のどの区間を使っているか**を秒で出す。将棋一番は上位がほぼ同じ 42〜66秒(サビ)だった。
3. 区間の頭と尻は、本家 MV の絵の変わり目に合わせて**コマ単位**で決める(41.375〜66.375・ちょうど600コマ)。
4. 曲は殿がスマホの YouTube アプリで付ける。拙者は**無音版**を作り、確かめ用に曲つき版も作る(アプリでの曲の頭＝区間の頭)。

## 1. 本家を1コマずつ測る(作る前に必ず)

| 測る物 | やり方 | 将棋一番で外した例 |
|---|---|---|
| 縦横比・fps | `ffprobe`。将棋一番の MV は **1080×1080 の正方形・24fps** | 横長と思い込み、押しつぶして比べていた |
| カットの頭 | フレーム差分の山を**コマ番号**で取る。秒を小数3桁に丸めて比べるな(16か所で1コマ遅れた) | 0.5秒刻みの13コマ割りで殿「ミリ秒単位でみろ」 |
| 字の表 | 字の変わり目もコマ番号で。全カットを見て抜けを確かめる | 最初の「私」を落とした |
| 字の層・大きさ・字形 | 字は**人物の後ろ**・画面の上3分の2を占める巨大な字。横並びで繰り返す字(隙だらけ・負けです・わかり/ました)の出だしの位置と大きさ。**筆の字**は 将棋・投了・将棋一番 の3か所だけ | 字を上の帯に小さく置いた・字形の違いを見落とした |
| ポーズ | カットごとに本家の絵を**大きくして**見て書き付ける。縮小した見本で書くと書き違える | 5カットのポーズ違い・投了と負けですの手の置き場所 |
| 人物の動き | 字を除いて人物だけの差分を見る。頭の位置を1コマずつ追う(下記) | 差分の数だけ見て「口パク」と決めつけ殿「全然違う」 |
| 寄り・引き | 寄りのカットは特徴点で縮尺の推移を測る | 最初の手が止まっていた・盤面が切れていた |

**人物の動きの正体(将棋一番)**: 1拍(約0.35秒・8〜9コマ)ごとに頭が画面の約2%ぶん3コマで伸び上がり、次の拍の手前でゆっくり沈む。ポーズの替わり目に1コマのぶれ。床のじたばたは2枚の絵を1コマごとに交互。

## 2. 絵の作り方

**一枚絵を後から伸縮・傾けして動かすのは手抜き**(殿「一枚絵をあと加工して手抜きしているよな」)。

1. **背景物(盤)は1枚だけ別に描く**。本家と同じ角度(真正面・上面は細い帯)で描き、全カット同じ絵を同じ位置に被せる。盤ごと描いた絵を使うと描くたびに大きさが変わる(殿「上から被せるだけよね？」)。
2. **人物は体全体で描く**(正座なら脚まで)。腰から上だけで描くと、盤からはみ出た所で切れ目が出て、隠す細工の継ぎはぎになる(殿「からだを中途半端にきってつくってるのが問題では？」)。
3. 各カットで**基本の絵**を描き、そこから**動きの絵**(半分上がり・伸び上がり・替わり目のぶれ)を「添付1枚目と同じ絵のまま○○だけ変えよ」と描き起こす。手本に本家のそのコマを番号で取り出して付ける。
4. 盤の手前に人物が出るカット(盤の上でじたばた)だけ、盤を描かぬ人物を描き、盤の前後の順を本家に合わせる。

## 3. 置き方(描いた絵をそろえる)

codex は描くたびに人物の大きさが変わる(カットどうし最大2割・同じポーズの描き起こしでも最大4%。殿「微妙に大きさ変わるのなんでなの」)。

1. 動きの絵 → 基本の絵 を、頭まわりの特徴点(ORB+RANSAC の相似変換)で重ねる(`full_align.py`)。
2. カットどうしは、基本の絵の頭の大きさを1つのカットの頭にそろえる(腰を支点に・ポーズごとの頭の位置は残す)。
3. 本家の人物の大きさと構えに合わせる。頭の大きさが同じでも、**盤の上に胴がどれだけ出るか**で大きさの印象が変わる(殿「おんりーがでかすぎるのでは？」→ 0.85倍にし頭のてっぺんの高さを本家にそろえて持ち上げた)。
4. 上がる量は描いた絵に任せず、置く位置で本家どおりに足す(伸び上がり20px・半分10px)。

## 4. 重ねる順と透け方

- 順: 背景 → 字 → (白いカットの頭2コマだけ盤面図が光る) → 人物 → 盤。投了だけは字が手の上。
- **盤の絵**: 背景の黄色は場所を問わず抜く(外とつながった所だけ抜くと駒台の内側に黄色が残る)。駒台の下・盤の下は**透かす**、地面の**影は残す**、**盤の脚の下端(床の線)より下には人物を映さぬ**(殿「駒台のした透過するだけ」「盤面のしたも透過ok影は残せ ただ足より下は切れ」)。
- 寄りのカットで画面を引く時は、**本家と同じ量だけ寄った所から引いて1倍で終える**。1倍から引くと絵の端が画面に入って切れる(目のアップ・わかりました・あれれで3度)。
- 縦 1080×1920 の真ん中に正方形の舞台(y=420〜1500)。上下の帯は**黒**(殿「四角だから上とした黒で埋めて」)。

## 5. 出す前の点検(機械で測る)

- 全カットの切り替わりが本家と同じコマか(切り替わりのコマの差分)
- 床の線より下・駒台の外の床に人物の色が出ていないか(全600コマ)
- 描いた絵の端で腕などが切れて画面に入っていないか(`edgecheck.py`)
- 盤の手前の面の位置と幅が全カットで同じか
- そのうえで、**本家(上)と自分の版(下)を同時に流す比べ動画**を作り、殿に見せる(`compare_v7.mp4`)

## 6. 殿の指摘の順(同じ所で叱られぬために)

0.5秒刻み→ミリ秒 / 止め絵→コマ数 / 口パク→分析 / 字が小さい・層が違う / ポーズ違い / 震え(1画素刻みの値をそのまま当てた) / 盤面の揺れ(盤の線を髪と取り違えた) / 最初の手が止まる / 白背景の盤面図 / 投了の手と字 / 筆の字 / 盤の角度 / 盤とおんりーを分けて描け / 一枚絵の後加工 / おんりーがでかい・字が隠れる / 9秒の将棋の字形 / 盤面が切れる / 口パクが速い / 駒台が消える / 後半の盤の大きさ / 大きさが微妙に変わる / 最初の「私」 / 盤の背景が透明でない / じたばたが盤の前 / 体が切れる(何度も) / 隙だらけの字 / 体を中途半端に切って作っている / 盤の下から見える / でかすぎる / 飛車・消の下半身 / 盤の透過は駒台の下だけ / 盤の下も透過・影・足より下は切る / わかりましたで体が切れる / 上下を黒に

## 7. 非公開アップ後の題・概要欄

殿が無音版をスマホで曲付きで上げる → 拙者が題・概要欄・タグを API で整える(公開状態は触らぬ)。

```
題: <メンバー>が「<曲名>」で<見どころ>!? 【ドズル社ファンアート】@dozle  #<曲名>
概要欄:
※ファンによる二次創作（非公式）です。ドズル社・<メンバー>さんご本人とは関係ありません。

もしも「<曲名>」を<メンバー>が歌ったら・・・
<一行の見どころ>

🎵 楽曲：
<曲名> / <作者> (feat.<歌声>)
<公式MVのURL>
MV（構図参考）：<MVの作り手>

■ドズル社公式チャンネル
https://www.youtube.com/@dozle

※公式ガイドラインに基づいて運営しています
https://www.dozle.jp/rule/

※イラストはAI画像生成を使用しています

#ドズル社 #ドズル社アート #<メンバー> #<曲名> #<作者> #shorts #マイクラ
```

切り抜きでも漫画でもないので【ドズル社切り抜き】と #漫画動画 は付けぬ。
**規約(2026-10-21 確認)**: 本家の映像・声を使わぬので切り抜きではなく、応援ガイドライン(https://www.dozle.jp/support_rule/)の「二次創作」に当たる。
「制作手法にかかわらず、公式作品または本人が制作したかのような誤解を与える表現」が禁止なので、題に【ドズル社ファンアート】、概要欄の頭に「非公式・ご本人とは関係ありません」を必ず入れる(同じ型のファン投稿もみな明記している)。
公式のファンアート用タグは #ドズル社アート。MV の画づくりをなぞった時は作り手を「MV（構図参考）」として明記する(申し立て・削除の求めがあれば従う)。メンバーの声を AI で作るのは禁止の線に触れるのでせぬ。音源のショート一覧で見つけてもらえるよう #<曲名> を題に入れる。

## 8. 道具の段取り

- codex は ChatGPT の2アカウントで手分けする(`CODEX_HOME=/home/murakami/.codex_acct1` で2つ目を同時に)。上限に当たったら `~/.codex/auth.json.acct*` の控えと device-auth で入り直し(URLは ntfy・コードは画面)。
- 組み立ては1コマずつ PIL で作って ffmpeg に流す(PNG を600枚書くと4分、流せば30秒)。
- 体全体の基本の絵 26枚+動きの絵 80枚で、2アカウントで約1時間。
