## 1. BGM は「カードで鳴らし、クリップでは鳴らさぬ」【最重要】

**全編に平坦に敷くのは誤り** (2026-08-06 殿「BGMさならすとこおかしいだろ」)。
ゲーム映像の区間は**叫び・掛け合いが主役**ゆえBGMを被せてはならぬ。

てぇてぇTOP42 の実測値 (BGM無 → 有):

| 箇所 | 実測 |
|------|------|
| カード部 (8s) | -37.4dB → **-27.7dB (+9.7dB)** |
| クリップ部 (62s) | -15.4dB → **-15.4dB (±0dB)** |

### 実装: 区間エンベロープ

concat の parts 一覧から**カード/導入/全記録スクロールの区間だけ**を拾い、
`volume` の enable 式で on/off する (ffmpeg 1パスで済む)。

```python
segs, t = [], 0.0
for tag, q in parts:
    d = dur_of(q)
    is_clip = tag.startswith("r") and os.path.basename(q).startswith("c")
    segs.append((t, t + d, not is_clip))
    t += d
# 隣接区間はマージし、境界に 0.6 秒のフェードを掛ける
env = "+".join(f"between(t,{a:.2f},{b:.2f})*min(1,(t-{a:.2f})/0.6)*min(1,({b:.2f}-t)/0.6)"
               for a, b in on)
# [1:a]atrim=0:{total},volume='0.40*({env})':eval=frame[bg];
# [0:a][bg]amix=inputs=2:duration=first:normalize=0,alimiter=limit=0.95[a]
```

- **`eval=frame` 必須** (既定は init 評価で式が効かぬ)
- **`normalize=0` 必須** — 既定の 1 だと本編音声が痩せる
- 仕上げに `alimiter=limit=0.95`
- 音量 **0.40** で カード部 ≈ -19dB / スクロール部 ≈ -18dB (実測)
- 検証は `volumedetect` で **カード部とクリップ部の両方**を測り、
  クリップ部が **±0.5dB 以内**であることを確認せよ

## 2. 順位カード (全画面・1920x1080)

`teetee_cards.py` の意匠を踏襲。黒背景ベタは味気ないと殿指摘 (2026-08-04)。

  (てぇてぇはペア名だが、企画にペアの概念がなければメンバー名にせよ。

  情報ボックス `#1a1a22` + 左端に金の縦線。見出し78px白 / コメント54px灰 `» ` 付き

- 1〜3位は**同じ絵の blur 版**も作る (ドラムロール用・`GaussianBlur(16)` + 「？？？」)

### 文字の落とし穴

- **矢印「→」(U+2190-21FF) は絵文字判定に食われて黙って消える**。
  `teetee_cards.is_emoji` から矢印域を外すこと (2026-08-04 QCで発覚)
- 絵文字は NotoColorEmoji で**別途描画**せねば消える。通常書体では豆腐にすらならぬ
- スクロール等で長い見出しを切る時は**省略記号を付ける** (尻切れは事故に見える)

## 4. 見出し・文言の鉄則

- **内輪語を出すな**: 「殿指名」「賛辞N件」等は視聴者に通じぬ。
  それぞれ「特別選出」「コメントN件の合計」へ (2026-08-04/06 殿指摘)
- **専門用語を開け**: 「クラッチ」→「〜寸前で生還」等
- **見出しは映像の事実のみ**。コメントの語尾から作文するな
  (詳細: `memory/feedback_ranking_headline_verify_frames.md`)
- 括弧書きの補足は基本不要 (「（連続2回避）」等は殿が削除指示)
