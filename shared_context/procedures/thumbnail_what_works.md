## 残った規則

### 1. ひとつの場面に、注目点をひとつ(強さ: 中・自chの中では一番はっきりした差)

- 主役(1人か1組)を手前・中央に置き、何が起きているかが絵だけで分かる作りにする。
- 5人以上を同じ大きさで横に並べ、主役のいない絵にしない。
- 数字:
  - 自chで主役ありの7本は、1日後の中央値 13,336。全員横並びの17本は 5,374。
  - 2本ずつ組にして比べると、119組中112組で主役ありが上回った。
  - 月ごとに見ても、6・8・9月の1位はどれも主役ありの回(死亡王1・死亡王2・エンドラとどめ)だった。
- 例外: 主役がいなくても、題材が絵だけで分かる舞台なら回った。逮捕王の鉄格子(1日後 10,152・10月の1位)。
- 「大きさ」ではない: 上位で主役ありの20枚のうち7枚は、主役が点ほどに小さかった。効くのは、注目点がひとつであること。

### 2. 顔を大きく・明るく・笑顔に・字を減らす、では回らない(強さ: 中)

- 7月総集編と8月総集編は、題も型も同じでサムネだけ大きく変えた(暗い・無表情 → 虹色・大笑い・顔を倍)。それでも1日後は 6,732 → 6,715 で動かなかった。
- 他chの下位20枚のうち14枚は、公式イラストの顔を大きく描いていたが、208〜1,325回だった。
- 字数・「w」・件数の数字は、あってもなくても差が出なかった。

### 3. 大見出しは、型の言葉より出来事か台詞を(強さ: 弱い・参考)

- 他chの上位30本で、見出しに「誰だ/TOP/ランキング/全部見せます/まとめ」を使った物は0本。多くは出来事か台詞だった(「流されるおんりーw」「半泣きのMEN」「秒でフラグ回収w」)。
- ただし自chの中で比べると、型の言葉による損は見えなかった。題材の違いと重なっている。

### 崩れた規則(使うな)

- 「大見出しは8字以下」: 上位では9字以上の方が多く回っていた。
- 「wを付ける」「件数の数字を出す」: 差が無い。
- 「AIの絵をやめてゲーム画面にする」: AIの絵は自chだけで使っており、効果を測れない。168pxでも誰かは分かる。

## 自chのサムネの直す所

- 24枚中17枚が、同じ5〜6人を同じ並び・同じ正面向きで並べている。168pxの一覧で、1本ずつ見分けがつかない。
- 合流縦断の旧3案も同じ型だった。5人の横並びで、背景だけが違う「1案のガチャ3回」になっていた。
- そのうえ、ホットバーは本編と違う作り物で、題の売り(黄昏の森で一人だけ)も絵に無かった。

## 出す前の点検表(毎回)

1. **注目点はひとつか。** 主役1人か1組を手前・中央に置き、何が起きているかが絵で分かるか。並べるなら、絵だけで題材が分かる舞台があるか。
2. **168pxの試験。** 幅168pxに縮め、自chの直近12本(`work/thumb_study/small/sheet_own.png`)と並べる。見分けがつくか・主役が誰か・大見出しが読めるか・何の場面かの4つを見る。1つでも落ちたら直す。
3. **コピーは動画の芯から。** 見出しは、その動画の芯の問い(視聴者が知りたいこと)か、問いへの引きにする。並べた場面すべてに当たるか、小見出しの言葉の種類(台詞か状況か)が揃っているかを確かめる(殿「キャッチコピーがおかしい」「動画のコンセプトは？」2026-10-24)。
   **題と同じ出来事か。** 題は出来事、サムネは芯の問いと役目を分ける。題の売りと、サムネの絵と大見出しが同じひとつの出来事を指しているか。
   - 小見出しの台詞は本家のテロップから引く。
   - 件数・期間・固有名詞は、作り直す前にも事実と照合する。前の版で通ったことは理由にならぬ(殿「上半期は外せ 全期間だから　なんでつくりなおしたのにそうなったの」2026-07-30)。
   - メンバーを形容する言葉は、ファンがコメントで実際に使う呼称だけ。AIの腐しラベル(ポンコツ等)は禁止(殿「おんりーポンコツとは？ファンに喧嘩売るのか？」2026-08-21)。
4. **絵は本編の実在の場面か。**
   - 使う場面の動画IDと秒を控える。
   - ホットバー・地図・ログなどの色・数・柄は、実物と照合する。
   - 画面に無い記号(輪・枠線・矢印・空想の地図)を足さない。個人の回数バッジ・天使の輪・英字バッジ・血やグロも入れない。
5. **ネタバレ。** 順位ものは1位を主役にしない(主役は1位ではない人か、問いを立てる構図)。縦断・シリーズものは結末を主な絵にしない。
6. **顔。** 正面〜斜め前・胸から上・顔は画面の高さの1/3以上。後ろ姿・真横・全身は禁止(殿「後ろ向いているのはありえない　違うパターンも作成せよ　全身映るのは小さくなるしだめ」2026-07-31・`feedback_thumbnail_face_closeup_rule`)。三面図は全身図なので、プロンプトに「三面図は見た目の参照・胸から上を大きく描け」と添える。生成したら顔の大きさと向きを確かめる。顔を大見出し・台詞・区切りの線で隠さない。組んだ後の1920版で、顔に字が被っていないか目で見る。
7. **ref。** 登場する全員ぶんの三面図を、一人一枚(縮めぬ原本)ずつ渡し、そのあとに背景を置く。顔の拡大は要らぬ(殿「三面図をわたしているのか？ かくだいなんていらんとおもうが」2026-10-24)。背景は本編のコマから、名前の帯・テロップ・HUD を切り落とし、ゲームの肌の人物は灰色で消す。**生成した絵(過去のサムネ・試作)は ref に入れるな。**画風がそちらへずれる(殿「えのたっちちがうけど三面図ちゃんと三人分いちまいずついれているのか？」2026-10-24)。生成したら、1人ずつ三面図と並べて見る。三面図に無い装飾(おんりーの胸の花など)を足す癖がある(`feedback_thumbnail_face_sheet_ref`)。
   - ref は三面図(`assets/dozle_jp/character/3views/*_3views.png`)と背景だけ。表情差分バスト・既製の表情 PNG(`selected/bust`・`expressions/gemini_v3`・`remotion-overlay/public/*_bust_rgba.png`)は使わぬ(殿「表情はつかわない。三面図だけ使う。表情はプロンプトで指示する。何度も言っている。二度と起こすな」2026-09-20)。
   - 「枚数が増えると薄まる」を理由に先回りで削らぬ。全部入れて描き、崩れた時だけ減らす(殿「何で背景削ったんいれたらいいじゃん」2026-10-04)。
   - codex に実際に渡った ref の枚数は `~/.codex/sessions/<年>/<月>/<日>/rollout-*.jsonl` の user message の画像で確かめる。問われたら記録で答える。
7.5. **プロンプト。** 書くのは表情・ポーズ・構図・背景・場面だけ。
   - 見た目(服・帽子・眼鏡・胸の花・色など)は書かぬ。見た目は「三面図の人物そのままに描け。足すな、省くな」の一文で足りる。三面図の画風(線・塗り・目の描き方)を守れと書く(殿「三面図とはどうゆうものかわかってる？」2026-10-24)。
   - 眼鏡は有無・形・色を一切書かぬ(殿「メガネに関する記述をするな」2026-05-23)。
   - 表情は日本語だけで「種類(強さ): 具体的な顔つき・手の動き」と書く。smile_r2 などの英語タグは使わぬ(殿「その英語タグのナレッジ消せ」2026-10-20)。
   - 動きは体の向き・足・腕で書く。「振り返って驚く」だけでは体が追手の方を向いて立ち止まった(殿「おらふが逃げてるように見えない」2026-10-24)。
   - 描かせるのは codex CLI(gpt-image)だけ。実行前に `unset OPENAI_API_KEY`。Gemini / Vertex は撤去済み(殿「金かかるから禁止 アカウント接続設定消せ」2026-10-09)。
8. **3案は意匠を振る。** 場面・主役・構図のどれかを案ごとに変える。同じプロンプトのガチャ3回にしない。
   - 殿の「3かい作れ」は3案1セットを1回。出したら指示を待ち、続けて作らぬ。前のセットは消さずに残す(殿「１せっとづつしかたのんでない」2026-04-25)。
8.5. **字は後入れ。** 絵を描くAIに字を描かせるな。字の置き場が区画に収まらず、台詞が斜めの区切りを越えて隣へはみ出した(殿「これさ、文字あといれ？」「わくはみでてるよな」2026-10-24)。
   - 区画ごとに字なしの絵を1枚ずつ描かせ、区切りの線と字は手元で重ねる。**どの区画にも、登場する全員ぶんの三面図を渡す**(その区画に出ない人も。出る人の分だけにしたら画風がずれた・殿「三面図いちまいずつわたせといったよな」)(`projects/dozle_kirinuki/scripts/gouryu_thumbnail_panels_codex.sh` → `gouryu_thumbnail_compose.py`)。
   - 台詞は、その高さで区画の内側に取れる幅に収まる大きさまでしか大きくしない。右下の再生時間の札(1920基準で y≥990)に被せない。
   - 正方形で描かせ、顔と胸の目印(ぼんじゅうるの『ぼ』など)の高さを数字で指定する。台詞の下に目印が隠れぬように。縦長で描かせたら全身寄りで顔が小さくなった。
   - 場面に要らぬ小道具(ベッドなど)は、背景の手本からも切り落としてから渡す(殿「ベッドやめろ」)。
9. **書き出し。** 16:9で中央クロップは禁止。上下48pxだけ削り、左右はぼかしで延ばす。1280x720の JPEG で2MB以下(`feedback_thumbnail_16x9_fit_and_2mb`)。
   - 48px削りは 1536x1024 など 3:2 で1枚描かせた時のもの。compose の流れは 1920x1080 から 1280x720(quality 92)へそのまま縮める。
   - compose は2MBを確かめぬ。自分でサイズを見る。PNG で失敗する前に JPEG にする。
10. **アップ後。** `youtube_uploader.py thumbnail <video_id> <path>` で付け、YouTube の maxres を取り直して目で見る。API の成功応答だけで確認済みとしない。
11. **記録。** 公開後、1日後と7日後の再生を、同じ月の自chの回と並べて記録する。その時「主役あり/横並び」「題材が絵で分かるか」のしるしを付ける。クリック率が取れれば併記する。
12. **出し方。**
   - 3案をレビューページに並べ、ntfy で URL を送る。画像は添付しない。殿が番号を選ぶ。AI が独断で選ばぬ。
   - 伺うのは、この点検表を全部通した版だけ(殿「何だチェックは最後してないのね」2026-10-23)。
   - 横長の非公開アップは、サムネを付けるまでが一式。本編URLだけで報告を終えない(殿「さむね作ってないじゃん」2026-10-10)。
   - 公開は殿の明示の指示があるまで出さない(殿「公開判断はわしの仕事」)。
