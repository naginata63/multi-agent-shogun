# /honke-telop — 本家そっくりの台詞字幕

## North Star

本家の画面の中に字幕を足すなら、本家の話者字幕と見分けがつかぬ型で足せ。浮いた字幕は足さぬ方がまし。

## なぜ要るか(殿の言葉)

1. 2026-10-23: 合流縦断の第8章で、おんりーの台詞を上中央の 34px の黒箱に要約で載せた。
   殿「なんで最後の写真企画 おんりーにテロップつけてる？」
2. 拙者は機能ごと外して済まそうとした。
   殿「字幕追加することは悪くないがフォントや表示する場所の考慮がかけている」
3. 本家の実物を測って合わせ直した。検査役に本家と並べて数値で比べさせ、4回直した。
   殿「字幕本物そっくりで気付かなかったわ バッチリすぎる 字幕機能もナレッジスキル化しておけ」(2026-10-24)

## 手順

### 1. 話者の型を測る(その話者で初めて使う時だけ)

その話者の本家の字幕が画面に出ている秒を、元動画から1つ選ぶ。1行の字幕が測りやすい。

```bash
cd projects/dozle_kirinuki
python3 scripts/honke_telop.py measure <元動画.mp4> <秒> <話者キー>
#   例: ... work/gouryu_yokonaga/input/RQMB9_hUh1k.mp4 3426 qnly
```

- `assets/honke_telop/<話者キー>.json`(縁の色・出典の秒)と `<話者キー>_icon.png`(本家のアイコンの切り出し)ができる。
- 出たアイコンは Read で必ず目で見よ。字形を拾っていないか、白い角丸の枠ごと切れているかを確かめる。
- 測り済みの型:
  - `qnly`(おんりー: 縁 204,149,3・RQMB9_hUh1k 3426秒)
  - `dozle`(ドズル: 縁 194,0,9・ZJuP6zxDnTM 2199秒)
  - ほかの話者(ぼんじゅうる・おらふくん・おおはらMEN・ゲスト)は、使う時に測れ。
  - 話者キーは `member_profiles.yaml` のキーにそろえる。

### 2. 文言を決める

- **本人の声を ASR で確かめ、本人の言葉に寄せる。** 言いよどみ・繰り返しを除く程度にとどめ、意味を足さぬ。要約を台詞の形で載せるな。
  - 例: `work/qwen_stt/merged_<ID>.json` の語の時刻、または `scripts/qwen_stt.py <wav> <json> --no-aligner`。
- 区切りは「、」を使わず、改行か空白で。
- 2行は `\n` で。本家は**短い行を上・長い行を下**が多い。
- 1行で幅 1450px を超える長さなら、2行に割れ。
- 出す秒は、声の頭の 0.1〜0.3 秒前から。消すのは言い終わりの 0.2〜0.7 秒後か、区間の尻まで。
- 本家がもう字幕を付けている秒には重ねるな。

### 3. 見本で確かめる

```bash
python3 scripts/honke_telop.py preview "写真撮ってたら\nこの家に火放って移動するかと思って" qnly <元動画> <その秒> out.jpg
```

同じ区間の本家の字幕のコマと並べて、Read で見比べよ。比べる所は字の大きさ・縁・アイコンの位置・下端。

### 4. 重ねる

```bash
python3 scripts/honke_telop.py render "<台詞>" <話者キー> cap.png   # 1920x1080 の透明PNG
```

ffmpeg では、**BT.709 に変えてから重ねよ**。既定の BT.601 で重ねると、金の縁が赤みに寄る。

```
[1:v]format=rgba,scale=out_color_matrix=bt709:out_range=tv,format=yuva420p[cp];[0:v][cp]overlay=0:0:enable='between(t,A,B)'
```

合流縦断の組立では、台本の区間の `notes` に `{"t0":元の秒,"t1":元の秒,"text":"…","style":"honke","icon":"<アイコンのパス>"}` と書けば重なる(`build_gouryu.py` の `clip()`)。

## 本家の実測値(render の既定値)

測った元: RQMB9_hUh1k 3416・3419・3426秒、おんりーの字幕。

| 項目 | 値 |
|---|---|
| 書体 | ラノベPOP(`assets/fonts/RanobePopB.otf`) |
| 字 | 白。横に対して縦 1.08 倍に伸ばす |
| 縁 | 話者色 0〜8px、その外に黒 14px まで |
| 2行 | 字の大きさ 94・行の頭から頭まで 106px・2行目の下端 y≈1011 |
| 1行 | 幅およそ 1450px まで大きくする(12字で「て」が 99×102px)。縁も同じ比で太らせ、6px 下げる |
| アイコン | 約 105×107・y≈910〜1013。一番長い行の頭の左・下の段に置く。字との間 46px |
| 全体 | 左右の中央 |

## やってはならぬこと

- 上中央・黒箱・小さな字で台詞字幕を足す(浮く)。
- 要約や作った言葉を台詞の形で載せる。
- 本家の字幕を消したり書き換えたりする(誤字は「※正しくは…」の注で。`feedback_dont_rewrite_honke_annotate`)。
- 測らずに他の話者の色やアイコンを流用する。
