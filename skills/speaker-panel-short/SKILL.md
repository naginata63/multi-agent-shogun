# 話者ミニキャラ型 縦ショート (speaker-panel-short)

## トリガーワード
「ミニキャラ型ショート」「上タイトル・下ミニキャラのショート」「本家の世界大会ショートの型で」「/speaker-panel-short」

## 概要
本家ショート(リズム天国・騒がしい世界大会 UjTDnASfO_8)の**型**を測って道具にしたもの。
**上=タイトル / 中=ゲーム画面(16:9) / 下=話している人の配布公式ミニキャラ / ゲーム画面の下端に字幕**の縦ショート(1080x1920)を、
横長本編の1場面(2〜3分)から40秒前後に組む。殿確定の練習作: `work/sekai_final/` (v5・非公開 Jx83mLaWMGI・2026-10-10)。

- 道具: `projects/dozle_kirinuki/scripts/speaker_panel_short.py spec.json`
- 素材の絵: `assets/official/ミニキャラ（ポーズB）/表情差分png/{メンバー}/*_{喜,怒,哀,楽,驚}.png`(配布公式絵・使用可 memory: reference_official_distributed_art)
- **本家の切り方・字幕をそのまま写すのは不可**。型(寸法・動き・構成の決まり)だけを使い、場面と切れ目と字幕は自分で決める

## 手順

### 1. 場面を選ぶ(拙者が選ぶ・殿に頭尻を投げない)
- 本編1本を音量(0.5秒ごと上位3%=叫び)＋字幕の[笑い]で2.5分窓に区切り、叫びが多い窓を候補に
- 決め手は**山場が1つはっきりある**こと(勝った/やられた/言い争い)。山場が無い窓は捨てる

### 2. 中身を読む(一次ソースは本家の焼き込みテロップ)
- `scene.mp4` を1fpsでシート化し、**本家テロップの文言と話者アイコン**を読む(STTはゲーム音楽に負けて読めないことが多い・2026-10-10実例)
- 0.1秒刻みで「画面切替」「テロップ帯の変化」「声の音量」を出す → 切れ目と字幕の出入りはこの変化点に合わせる

### 3. 構成(本家の決まり)
| 決まり | 本家の値 |
|---|---|
| 尺 | 約40秒(39.7秒) |
| カット | 9本・平均4.4秒。2.5分を40秒に圧縮 |
| ループ | **山場の言いかけを頭に1〜3秒** → 前振りから順に → 最後に同じ山場へ戻って言い切る |
| 間詰め | セリフの無い間は2秒単位で詰める(同じ発言の途中でも詰める) |
| 合いの手 | 「え?」「多くない?」など短い合いの手も拾って1枚ずつ出す |

### 4. spec を書く(時刻はすべて完成動画の秒)
```json
{"src": "edit.mp4", "out": "v1/out.mp4", "title": [["ついに","#FFE600"],["世界制覇","#E60012"]],
 "charas": [{"t0":0,"t1":1.8,"who":[["dozle","驚"]]}],
 "texts":  [{"t0":0,"t1":1.8,"text":"見てるか!?","style":"shout","speaker":"dozle"}]}
```
- **切れ目**: 本編から1本ずつ `-ss` でコマ数ちょうどに切り、音はPCMで長さを揃えて concat(memory: concat copy は音がずれる)
- **字幕の種類**: normal(白字+話者色の縁・揺らさない) / shout(白字+話者色縁・大・斜体) / shout_fill(話者色字+白縁) / band(黒帯の大字) / serif(明朝の白抜き大字) / label(黒い小札)
- **ミニキャラ**: 話している間だけ出す(話者が変わる・黙ると消す)。叫びは「驚」、怒鳴りは「怒」、勝ち・笑いは「喜/楽」、落ち着いた語りは「哀(素の顔)」。2人の掛け合い=2人並び、全員の叫び=4人並び

### 5. 組む → 見る
- `python3 scripts/speaker_panel_short.py spec.json`(約1分40秒/45秒尺)
- 0.5秒ごとのシート＋出だしの1コマずつ(30fps)で確かめる

## 道具に入っている実測値(本家と同縮尺で並べて測った)
| 項目 | 値 |
|---|---|
| タイトル | 中心y=360・極太ゴシック・2色(黄/赤)・黒縁 |
| ゲーム画面 | y=456〜1120(高さ664に合わせ左右を切る)・背景は同じ映像を全面に引き伸ばして強くぼかす |
| 字幕 | 中心y=1080(ゲーム画面の下端に重ねる) |
| 本家焼き込みテロップ | 元画面 y≈900〜1060 → こちらの字幕を出す間だけゲーム画面の下116pxをぼかして隠す(二重字幕防止) |
| ミニキャラ | **人ごとに大きさを変え、頭のてっぺんを y≈1125 にそろえる**(ドズル0.42/おらふ0.47/ぼん0.36/MEN0.52/おんりー0.55/ネコおじ0.43倍)。2人=0.9倍・4人=0.66倍 |
| 出方(叫び字幕) | 出た直後のコマだけ上下に跳ねて止まる: 上53→下17→上27px→止 |
| 出方(ミニキャラ) | 上34→18→4→14px→止(約0.17秒)。**傾けない・拡大しない・揺れ続けない** |

## 失敗の記録(2026-10-10 練習で踏んだ順)
1. 焼き込みテロップの上に字幕を置いて二重になった → 帯ぼかし
2. 背景のぼかしが弱く本家テロップの文字が透けた → boxblur 40
3. 「揺らしながら出す」を「ずっと傾けて揺らす」「1.1倍で出て縮む」と思い込んだ → 1コマずつ測ったら**出だし数コマの上下ガタガタだけ**だった。動きは推測せず30fpsで実測せよ
4. 全員を同じ縮尺で置き、おらふは顔しか出ず・ドズルは大きすぎた → 人ごとの縮尺と頭の高さ
5. 文字起こしが音楽に負けて合いの手を拾えなかった → 本家焼き込みテロップを一次ソースに
