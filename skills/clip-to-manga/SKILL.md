# /clip-to-manga — クリップ→漫画ショート 一気通貫フロー

2026-08-20〜21 の「ぼんじゅうるさんです」「おんりー使用禁止」2作で確立した実戦手順。
各段の実装例は `work/manga_tetsu/` `work/manga_tetsu_b/` にそのまま残っている。

## North Star

**セリフは実発話・外見は三面図・選ぶのは殿。** この3点を機械で保証しながら、
殿の手数（確認ポイント）を「セリフ確定」「構成案OK」「ガチャ選定」の3回に絞る。

## 全体フロー

```
入力: 確定済みクリップ mp4（clip_editor 8097-8099系で殿が書き出した物）
① STT           qwen_stt.py → 語単位ms
② 行割り         間0.55秒 or 18字で機械分割 → telop.json
③ 本家テロップ訂正  下部260pxの帯を1.2秒刻みで抽出→目視読取→文言/話者を正解に
④ 殿確定 ────── telop_editor.py (空きポート) で殿が修正・💾保存 【殿確認1】
⑤ 出演裏取り      各行中央のフルフレーム抽出→誰が映るか確定
⑥ 宛て書き構成案   panels JSON起草→実フレーム付き検分ページ 【殿確認2】
⑦ simple変換     共通しっぽ結合→機械検査→codexガチャ1周
⑧ ギャラリー選定   1周見せ→指摘コマだけ打ち直し (2周は殿要望時のみ) 【殿確認3】
⑨ 動画組み       segs.json(殿確定セリフ時刻)→build→コマ同期エディタ併設
⑩ 非公開アップ    ナレッジ概要欄テンプレ・private必須
```

## ① STT + ② 行割り

```bash
/usr/bin/python3 scripts/qwen_stt.py <clip.mp4> <out>/edit_stt.json   # venv経由禁止(qwen_asrは~/.local)
```
行割り: 語間0.55秒超 or 累積18字で切る。`{"video":..., "lines":[{start,end,text}]}` を telop.json に。

## ③ 本家テロップ訂正（最重要・データの正解はここ）

- `crop=iw:260:0:ih-260` で下部帯を **1.2秒刻み**で抽出、PILで縦積みシートにして**目視読取**
  （ffmpegのvstackはJPEG多数でmalloc落ちする → PILを使え）
- 本家テロップの**文言が正**。STTは時刻の当たり付けと、テロップ化されなかった口語の補いのみ
- **話者はテロップ色/アイコンで判定**（赤=ドズル 紫=ぼん 黄=おんりー 水色=おらふ 桃=MEN）
- 行の隙間もフレーム抽出して取りこぼし検査。「確定行の外にSTT語ゼロ」を機械検証

## ④ 殿確定（telop_editor）

```bash
systemd-run --user --unit telop-editor-<name> --working-directory=<proj> \
  /usr/bin/python3 scripts/telop_editor.py --json <telop.json> --port <空きポート>
```
ポートは 8100 から。殿が文言・話者チップ・時刻を直して💾保存。**保存後の telop.json が唯一の原本**。

## ⑤ 出演裏取り + ⑥ 宛て書き構成案

- 各行中央のフルフレームを抽出→**誰が映るか**を確定（居ない者は描かない）
- panels JSON起草の鉄則:
  - **1発話=1コマ**が基本。同話者の連続・被せ相槌は1コマに同居
  - 被せ相槌で本人を描かない時は**アイコン吹き出し**（吹き出し左肩に顔・尻尾なし・そのキャラのrefを同梱）
  - 大ゴマ=決め台詞。オチは別に立てる
  - **メガネ/眼鏡の記述は一切禁止**（三面図refに全面委任・「丸メガネ必須」で殿叱責済み）
  - MENゴーグルは「目を覆う装着」のみ言及可（共通しっぽに既在）
  - 単独コマは「【最重要】描く人物は◯◯ただ一人。他の人物を一切描くな」を必ず書く
  - ゲーム由来の演出はモブ/UIで表現可: ログアウト=体がブロック片にほどける+
    システムログ風一行（**ゲーム内名の綴りを明記**: Dooozle/Qnly_qdm/ooharaMEN/bonj55/ORAMAINECRAF）、
    種明かし=モブ+注釈テロップの図解インサート
  - 特殊演出（歌の使い回し・退出など）は**構成案の段で殿に問う**
- 検分ページ: コマごとに実フレーム+セリフ+演出を並べ 8080 配下に → 殿OK

## ⑦ simple変換 + ガチャ

- 共通しっぽは既存 simple JSON から流用し、舞台描写だけ差し替え
- **機械検査必須**: `assert "メガネ" not in prompt` 全数 / refと登場者の一対一照合
- ```bash
  bash scripts/codex_manga_batch.sh <panels_simple.json> <outdir> 1024x1024
  ```
  (`unset OPENAI_API_KEY` はスクリプト内・ChatGPTサブスク枠)

## ⑧ ギャラリー選定

- **まず1周だけ見せる**（2周自動連発は殿叱責済み「なぜ2週？いったんみせろ」）
- 全数検分して所見を添える: 人数超過・綴り・メガネ・退出表現の有無
- 指摘コマだけ fix JSON で打ち直し。追加周回は殿の「あと2周まわして」等の指示時のみ
- 複数案は a(現行)/b/c 横並びギャラリー、選定は「bbcbbcacbb」の10文字一括形式

## ⑨ 動画組み

- `segs.json`: 各コマの start は**殿確定 telop.json の行境界**から
- build script は `-loop 1 -t dur -i png` × N → concat → クリップ原音を `-map n:a`（音は無加工）
- **1:1パネルなら1:1動画**（縦型盲従禁止）
- コマ同期エディタを併設: `panel_sync_editor.py --segs --panels --audio --port`（調整→保存→再組み）

## ⑩ 非公開アップ

- 概要欄は `shared_context/procedures/manga_short_description_format.md` のテンプレ**そのまま**
  （■ドズル社公式チャンネル=敬称なし・AI画像生成注記・タグ順序固定）
- `--privacy private` 必須。公開・削除は殿の専権。旧版の削除も殿の手

## 禁止・注意（本フローで実際に踏んだ地雷）

| 地雷 | 回避 |
|---|---|
| プロンプトに「丸メガネ」等の外見記述 | 三面図refに委任・機械検査で締め出す |
| 単独コマに謎人物混入 | 「ただ一人・他は描くな」明記 + ref一対一 |
| ゲーム名の綴り崩れ (Only_qdm等) | 正字をプロンプトに明記 |
| 2周ガチャの勝手な連発 | 1周見せ→指摘分のみ。周回追加は殿の指示 |
| 音声を目分量で切り貼り | 間の挿入はカット境界の累積表が原本 |
| 裏処理の完了見張り自作 | run_in_background 標準 (feedback_bg_job_completion_detection) |
